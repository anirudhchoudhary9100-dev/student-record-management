## Purpose of AI Use
ChatGPT was used as a learning assistant during the project. It was used to help understand the assignment requirements, design simple CGPA-based academic advice, review the logic, and improve the GitHub documentation.

The C program does **not** connect to ChatGPT or any external AI API. The final academic recommendations are generated by C `if-else` statements.
